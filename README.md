# rent-a-car-system-group-9
CMPE341 - Rent a Car Database Management Project - Group 9

## Frontend preview (no backend needed)

```
node tools/dev-server.js
```

Open http://localhost:5500 — the site runs in demo mode (`MODE = "mock"` in `js/api.js`), data is kept in your browser.

| Page | URL |
|---|---|
| Home | `/` |
| Cars | `/cars` |
| Log in | `/login` |
| Admin panel | `/admin` |

Test accounts: admin `admin` / `Admin123!`, customer `demo1` / `Customer123!`.
